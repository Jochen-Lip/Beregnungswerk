1und1 SCom ONT TOOL

Das ONT TOOL berechnet Benutzername und Passwort für das 1&1 SCom-Modem (Sercomm Glasfaser-ONT) aus der Modem-ID bzw. Seriennummer auf dem Aufkleber.

Modem-ID (Seriennummer) vom Aufkleber eingeben. Benutzername ist immer 1UND1. Die Berechnung läuft nur lokal im Browser.

Modem-ID intern
Letzte 5 Zeichen
Benutzername 1UND1
Passwort

Prefix G6m%Z + letzte 5 Zeichen der intern übersetzten ID. Hex-Prefix 53434F4D wird als SCOM gelesen.

1und1 SCom Modem Passwort

Mit diesem Rechner erhältst du die Zugangsdaten für das 1und1 Glasfaser-Modem: Benutzername 1UND1 und das Passwort aus der SCOM-Modem-ID. Das gilt für das Sercomm-ONT (u. a. FG1000B.11), also das 1&1 Glasfaser-Netzanschlussgerät.

ONT TOOL

ONT TOOL berechnet die Zugangsdaten für das 1und1 SCom-Modem. Es hilft beim Login an der Weboberfläche des Glasfaser-ONT.
